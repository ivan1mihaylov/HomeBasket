Open Food Facts keeps the brand out of the product name, which produced
shopping list entries like "Original Taste 1,5 l". The brand is now put in
front of the name when it is not already part of it, so the same product comes
out as "Coca-Cola Original Taste 1,5 l".

This applies to products looked up from now on. Anything already in your
dictionary keeps the name it has — rename it from the card if you want.

Needs [HomeBasket-Card](https://github.com/ivan1mihaylov/HomeBasket-Card)
0.2.0 or newer.
